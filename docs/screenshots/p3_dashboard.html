📡 Implemented Endpoints

GET /api/events → List events from data/events.json
GET /api/events/:id → Single event lookup
POST /api/events → Create event + emit 'eventCreated'
POST /api/register → Atomic registration + emit 'registrationCreated' + 'capacityAlert'
GET /api/registrations → List registrations from data/registrations.json
POST /api/cancel-registration → Cancel registration + restore capacity
GET /api/logs/stream → Stream logs/audit.log via fs.createReadStream
GET /api/export/csv → Stream events as CSV via stream.Transform
